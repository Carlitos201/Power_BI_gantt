# Dashboard Gantt de gobernanza de datos en Power BI

Ejemplo de dashboard para planificar y dar seguimiento a un proyecto de implementación de gobernanza de datos basado en DAMA-DMBOK.

## Archivos

- `Dashboard_Gantt_Gobernanza_Datos.pbix`: informe interactivo de Power BI.
- `Base_Gantt_Gobernanza_Datos.xlsx`: datos usados por el informe.

## Descargar el proyecto

### Descargar todos los archivos

1. Abre la página principal de este repositorio en GitHub.
2. Selecciona **Code** y luego **Download ZIP**.
3. Descomprime el archivo ZIP en tu equipo.

Consulta la [guía oficial de GitHub para descargar un repositorio](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives).

### Descargar con Git

Si tienes Git instalado, puedes clonar el repositorio con este comando:

```bash
git clone https://github.com/USUARIO/REPOSITORIO.git
```

Reemplaza `USUARIO` y `REPOSITORIO` por los datos que aparecen en la dirección del repositorio. Consulta la [guía oficial para clonar un repositorio](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository).

## Abrir y actualizar el informe

1. Conserva el archivo `.pbix` y el `.xlsx` en la misma carpeta.
2. Abre el archivo `.pbix` con Power BI Desktop.
3. Si Power BI no encuentra el Excel al actualizar, cambia la ruta del origen de datos para seleccionar el archivo descargado y vuelve a actualizar el informe.
4. Si modificas el Excel, conserva los nombres de las hojas, tablas y columnas que usa el informe.

> Si el repositorio es privado, necesitarás permiso para acceder y descargar sus archivos.
